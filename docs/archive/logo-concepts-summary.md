# RouteFlow Logo Concepts — Design Summary

**Project**: RouteFlow — سامانه فروش، پخش و مدیریت مسیر  
**Visual Thesis**: "مریدین (Muridin) — a cool, quiet workbench, lit from the north"  
**Primary Accent**: Ocean `#006D77`  
**Ground**: Cool blue-grey `#F1F3F6`  
**Default Theme**: Light (not dark)  
**RTL/Persian**: Required  
**Domain**: Sales, distribution, route management, Tehran province territory mapping

---

## Concept Overview

| # | Concept | Core Metaphor | Best For |
|---|---------|---------------|----------|
| 1 | **Route Wave** | Flowing path → ocean wave | Brand recognition, fluidity |
| 2 | **Network Pin** | Location pin → connected nodes | Territory coverage, CRM |
| 3 | **Compass Flow** | Compass rose → directional flow | Navigation, driver mode |
| 4 | **Kufic Monogram** | Persian initials ر + ف | Local identity, cultural resonance |
| 5 | **Terrain Contour** | Topographic lines → district map | Map/territory focus |
| 6 | **Delivery Path** | Box → route → destination | Logistics, order-to-cash |
| 7 | **Ocean Current** | Streamlines → fluid dynamics | Ocean accent, calm precision |
| 8 | **Geometric Mark** | Modular RF grid | Small sizes, app icons, favicon |
| 9 | **Map Fold** | Folded map corner → route | Map surface, spatial view |
| 10 | **Arrow Ligature** | R + F + → merged glyph | Minimalist, memorable mark |
