# Demo Data Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use /long-haul-development.md to implement this plan task-by-task (disk-backed plan + journal, `/newtask` relay, review gates). For a plan small enough to finish in one session, /executing-plans.md is the simpler inline path. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a throwaway demo database — `data/routeflow.demo.db` — containing every data-backed section of the app, with the books balanced, one login per role, and two tenants.

**Architecture:** One script, `scripts/seed-demo.ts`, that calls the application's own repository layer (`getDb`, `createOrder`, `recordDelivery`, `recordPaymentTxn`, `postExpense`, `postPurchase`) rather than re-implementing its business rules. A ~25-line Node module-resolution hook makes that possible by letting `node --experimental-strip-types` resolve the `@/lib/...` alias that Node alone cannot. Everything runs in one transaction; the seed asserts 18 invariants before committing and rolls back on any failure.

**Tech Stack:** Node 26 (`node:sqlite` `DatabaseSync`, `node:module` `registerHooks`), TypeScript type-stripping (no build step), Vitest, SQLite. No new npm dependencies.

**Spec:** `docs/superpowers/specs/2026-10-02-demo-data-design.md` (committed `a373f8e`, corrected `020e752`).

## Read this first — nine things that will waste your day

Each was verified by probe during the spec's audit. Each has already cost this repository
real time.

1. **`node --experimental-strip-types` cannot resolve `@/lib/...`.** Nor extensionless relative
   imports, nor `next/server`. That is why every existing script
   (`scripts/seed-districts.ts:11-13`) re-declares the schema by hand. **Task 1 fixes all
   three and must come first — nothing else works until it does.**

2. **`lib/session.ts:1` imports `next/server` as a VALUE**, and `lib/repo/margin.ts:14`
   imports a value (`orderFilter`) from it. The hook must stub `next/*` or phase 09 dies with
   `ERR_MODULE_NOT_FOUND: .../node_modules/next/server`.

3. **`module.register()` is deprecated on Node 26** (`[DEP0205]`). Use `registerHooks()`.

4. **`lib/db.ts:21` reads `ROUTEFLOW_DB_PATH` at MODULE LOAD** into a `const`, and `getDb()`
   memoises into a module-level `_db` (`lib/db.ts:23`). Set the env var in the shell
   **before** the process imports anything — you cannot set it inside the script.

5. **`facilities` has `lat REAL NOT NULL, lng REAL NOT NULL` and `getDb()` creates NO default
   facility**, but `stock_movements.facility_id` is `NOT NULL REFERENCES facilities(id)`.
   Phase 01 must create one or every stock movement fails.

6. **`users.role` CHECK also accepts `'salesperson'` and `'driver'`** — two legacy values beyond
   the seven in `lib/roles.ts`. Seed the seven real roles; do not use those two.

7. **Churn will not train without lapsed customers.** `trainChurnFromLapses` is a no-op below
   `MIN_TRAIN_ROWS = 10` (`lib/repo/churn.ts:24`), and a label needs a customer active at
   `asOf − 60d` who then went quiet for 60 days. Phase 04 creates ~30 deliberately.

8. **`refreshAll` does NOT train predictions.** Forecast/churn/capacity need
   `refreshPredictions` (`lib/repo/predictionRefresh.ts:19`) as well.

9. **`scripts/` is exempt from the repo-boundary rule.** `tests/repo-boundary.test.ts` greps
   only `app lib`, so raw SQL in `scripts/seed-demo.ts` is legal and expected.

10. **THE BIGGEST LANDMINE: nine writers open their own `BEGIN IMMEDIATE`, and SQLite
    refuses to nest.** Verified — `db.exec("BEGIN IMMEDIATE")` twice throws
    `cannot start a transaction within a transaction`. The offenders are `createOrder`
    (`lib/orders.ts:206`), `recordDelivery` (`lib/delivery.ts:291`), `recordPayment` and
    three siblings (`lib/repo/payments.ts:354,391,510,534`), `postJournalIn`
    (`lib/repo/ledger.ts:176`) and `recordExpense` (`lib/repo/ledgerPostings.ts:264`).

    **The codebase already solved this and the convention is the answer.** Three names for
    every writer:
    - `foo(db, …)` — takes a `db`, opens NO transaction. **Safe inside our transaction.**
    - `fooTxn(db, …)` — takes a `db`, opens NO transaction. Same thing.
    - `foo(…)` / `fooIn(…)` — opens its OWN transaction. **Crashes if we already have one.**

    So inside the seed you must use: **`createOrder(db, …)`**, **`recordDelivery(db, …)`**,
    **`recordPaymentTxn(db, …)`**, **`postJournal(db, …)`** via the `post*Postings`
    functions (which take `db` and open nothing), and **`recomputeOrderPaymentTxn(db, …)`**.
    Calling `recordPayment` or `postJournalIn` instead will throw
    `cannot start a transaction within a transaction` on the very first call.

    Note `postReceipt`/`postExpense`/`postPurchase`/`postDeliveryRecognition` take `db` as
    their FIRST argument and open nothing — they are the `db` flavour already. Only the
    `record*` wrappers open transactions.

/** Module-resolution hook that lets a plain `node` script import the app's own modules.
 *
 *  `node --experimental-strip-types` runs .ts, but it resolves imports with Node's rules
 *  and none of them are this project's rules. Three gaps, all load-bearing:
 *
 *    1. `@/x` is a tsconfig path alias. Node knows nothing about tsconfig.
 *    2. `lib/repo/ledger.ts` imports `"./payments"` — no extension. Node ESM requires one.
 *    3. `lib/session.ts:1` imports `next/server` as a VALUE, and `lib/repo/margin.ts:14`
 *       imports a value (`orderFilter`) from it. `next/server` is not resolvable outside
 *       Next's bundler, and because it is not a type-only import, stripping cannot erase
 *       it. A stub is the answer: the seed never calls NextRequest or NextResponse.
 *
 *  This is why every existing script re-declares the schema by hand — see the comment at
 *  scripts/seed-districts.ts:11-13. That workaround cost the repo three seed scripts and
 *  is what let demo data drift away from the app's business rules.
 *
 *  `registerHooks` rather than `register`: the latter is [DEP0205] as of Node 26.
 */
import { pathToFileURL } from "node:url";
import { existsSync } from "node:fs";
import path from "node:path";

const ROOT = path.resolve(path.dirname(new URL(import.meta.url).pathname), "..");

/** `next/server` as an importable stub. Only what a module might destructure at load time. */
const NEXT_STUB =
  "data:text/javascript," +
  "export class NextRequest {}" +
  "export const NextResponse={json:()=>({}),redirect:()=>{},next:()=>({})," +
  "cookies:{get:()=>undefined,set:()=>{},delete:()=>{}};" +
  "export const NextHeaders=undefined;";

/** The file to load for a specifier, or null. Exact file before directory, always. */
function resolveFile(base) {
  for (const candidate of [base, `${base}.ts`, `${base}.tsx`, path.join(base, "index.ts")]) {
    if (existsSync(candidate) && !candidate.endsWith(path.sep)) return candidate;
  }
  return null;
}

export function resolve(specifier, context, nextResolve) {
  if (specifier.startsWith("@/")) {
    const found = resolveFile(path.join(ROOT, specifier.slice(2)));
    if (found) return nextResolve(pathToFileURL(found).href, context);
  }
  if (specifier.startsWith(".") && context.parentURL) {
    const parentDir = path.dirname(new URL(context.parentURL).pathname);
    const found = resolveFile(path.resolve(parentDir, specifier));
    if (found) return nextResolve(pathToFileURL(found).href, context);
  }
  if (specifier.startsWith("next/")) {
    return nextResolve(NEXT_STUB, context);
  }
  return nextResolve(specifier, context);
}

export function makeRng(seed: number): Rng {
  let state = seed >>> 0;
  const next = () => {
    state = (state + 0x6d2b79f5) >>> 0;
    let t = state;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
  return {
    next,
    int: (min, max) => min + Math.floor(next() * (max - min + 1)),
    chance: (p) => next() < p,
    pick: <T,>(items: readonly T[]) => items[Math.floor(next() * items.length)],
    flags: (count, p) => Array.from({ length: count }, () => next() < p),
  };
}

    h ^= isoDate.charCodeAt(i);

  return h >>> 0;
